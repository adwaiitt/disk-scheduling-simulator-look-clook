    Differences with Respect to the Original / Basic LOOK Algorithm
    Academic Literature Analysis
    1. Directional Optimization & Analysis
    Basic LOOK: Blindly executes in whatever direction is passed by the caller (typically defaulting to UPWARD) without analyzing pending cylinder distribution.

    Paper's LOOK: Explicitly evaluates both LOOK (Upward) and LOOK (Downward). Proves that on typical real-world distributions (with head near lower tracks), LOOK (Downward) eliminates the large initial turnaround swing, cutting head travel dramatically (e.g., 208 tracks vs 299 tracks on Sample 1).
    2. Deterministic Queue Rearrangement
    Basic LOOK: Modeled as dynamic runtime head sweeping with immediate proximity checks.

    Paper's LOOK: Rearranges the incoming I/O request queue statically before physical execution into two monotonic subsets: Q = [R_lower ↓, R_higher ↑] (for Downward), minimizing disk controller seek recomputation overhead.
    3. Wild Swing Elimination vs. SSTF
    Basic LOOK: Compared primarily against SCAN (preventing edge seeks to cylinder 0/199).

    Paper's LOOK: Benchmarked against FCFS and SSTF. Proves LOOK (Downward) achieves equal or superior seek performance to SSTF (e.g., 208 vs 236 in Sample 1; 370 vs 590 in Sample 5) while completely eliminating starvation which plagues SSTF.
    4. Seek Distance Formula Structure
    Basic LOOK: Computed step-by-step incrementally.

    Paper's Closed-Form Model:
    • Downward: THM = (H_0 - min(R)) + (max(R) - min(R))
    • Upward: THM = (max(R) - H_0) + (max(R) - min(R))
    Proves that when H_0 < (max + min) / 2, Downward is mathematically guaranteed to be superior.

    Differences with Respect to the Original / Basic C-LOOK Algorithm
    Academic Literature Analysis
    1. Strict Unidirectional Upward Sweep
    Basic C-LOOK: Often implemented with arbitrary upward or downward circular sweeping modes.

    Paper's C-LOOK: Strictly formalized as an upward scan starting from initial head to the highest pending cylinder, followed by an immediate return swing to the lowest pending cylinder, treating the platter as circular with the highest track adjacent to the lowest.
    2. Full Return Swing Mechanical Accounting
    Basic C-LOOK: Some educational tools classify the return jump as an idealized 0-cost logical repositioning.

    Paper's C-LOOK: Explicitly accounts for the actuator slew distance of the return swing (e.g. 183 → 14 = 169 tracks) in the Total Head Movement metric (322 tracks on Sample 1), faithfully modeling physical drive mechanics and seek latency.
    3. Load-Dependent Efficiency Discovery
    Basic C-LOOK: Described generally as "superior due to uniform wait times".

    Paper's C-LOOK: Highlights that at light and moderate loads, C-LOOK has worse head movement than LOOK and SSTF due to the return swing penalty. It is only superior at high multiprogramming loads because it eliminates starvation and bounds maximum waiting variance.
    4. Two-Phase Ascending Queue Reordering
    Basic C-LOOK: Relies on pointer increments across modular arrays.

    Paper's C-LOOK: Employs a deterministic two-partition sorted queue: Q = [R_higher ↑, R_lower ↑]. The disk head services R_higher, executes the return swing straight to min(R_lower), and finishes the ascending sweep.
